# Source selection

This candidate contains the shared Node server, feed generation and validation,
channel schemas, analytics, operator views and local tests. The separately
included Python stream-relay service retains its own setup requirements.

Original Git history, production hosts/profiles, operations inventories,
monitoring deployments, credentials, private agent records, customer media and
artwork, signing material, generated state and installed dependencies are not
copied. Historical Python feed tooling is not the Node feed producer and is not
included. Original private repositories remain unchanged.

This is source preparation, not a transfer of production. See the release and
licensing status for unverified containers, known billing limitations, dependency
review and outstanding ownership/notice requirements.
