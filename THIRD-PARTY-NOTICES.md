# Third-party notices

`THIRD-PARTY-LICENSES.json` preserves full license/notice texts from the installed
npm production dependency graph, with each package name/version, source filename
and text hash. Text embedded in an upstream README is preserved when that is the
package's license location. `DEPENDENCY-LICENSE-INVENTORY.json` separately records
declared metadata for development tooling and all lockfile packages.

This collection is not a legal clearance, does not grant first-party rights and
does not cover externally hosted Chart.js/fonts, FFmpeg binaries, Python relay
dependencies or container/system packages. Their licenses, source-offer obligations
where applicable and distribution notices require review for the exact artifact
being distributed. Do not apply the proposed church license to third-party code.

The original first-party package manifest declares ISC; the declaration remains
preserved. Prior grants and actual ownership must be resolved before representing
that all source can be restricted to noncommercial/church-only use.
